## General Evaluation

**1. Overall Evaluation**

The **First Cloud AI Journey** program provides an opportunity to learn about **Amazon Web Services (AWS)** through theoretical lessons and practical exercises. The program content helps develop a basic understanding of cloud computing and how to deploy applications on AWS.

**2. Learning Environment**

The program provides learning materials, practical exercises, and knowledge-sharing activities. The learning environment creates opportunities to explore AWS services and discuss difficulties encountered during implementation.

**3. Mentor Support**

The knowledge sharing and guidance provided by mentors and the **AWS Study Group** community are valuable sources of support when learning new concepts, especially for those with limited experience in cloud computing.

**4. Learning Experience**

The practical exercises help participants become familiar with services such as **Amazon EC2**, **Amazon S3**, **AWS Lambda**, **API Gateway**, and **IAM**.

Through the **CloudManga** project, the acquired knowledge was applied to building a web application based on **Serverless** architecture. The implementation process also revealed challenges in configuring access permissions, connecting APIs, and troubleshooting errors.

**5. Skills Acquired**

After the internship, the following skills have been improved at a basic level:

- Foundational knowledge of **AWS Cloud**.
- Ability to use the **AWS Management Console**.
- Basic understanding of **Serverless** architecture.
- Skills in troubleshooting errors and searching for technical documentation.
- Skills in preparing technical documentation and reporting the implementation process.

## Suggestions

Some suggestions to improve learning effectiveness include:

- Provide additional instructional materials for beginners.
- Increase the number of practical exercises that combine multiple **AWS** services.
- Provide more examples of common errors and how to resolve them.
- Allocate more time for guidance and feedback during the **Capstone** project.
- Add more content about cost management and AWS resource security.

## Final Thoughts

The **First Cloud AI Journey** program is a valuable opportunity to explore **Cloud Computing** and gain practical experience.

Although my current knowledge and skills still have many limitations, the internship helped me establish an initial foundation in **AWS** and gain a clearer understanding of the areas I need to continue studying.

The experience gained from the **CloudManga** project will serve as a foundation for further improving my programming skills, exploring cloud services, and developing my professional capabilities in the future.
