## Objectives

Build the user interface for **CloudManga** using **HTML**, **CSS**, and **JavaScript**, while connecting to **Amazon API Gateway** to access backend features.

## Implementation Steps

1. **Build the Interface:** Homepage, search functionality, and manga details page.
2. **Build the Manga Reader:** Display JPG pages stored in **Amazon S3**.
3. **Integrate Login and Reviews:** Connect **Amazon Cognito** and the Reviews API.

Once completed, CloudManga can display manga data, read chapters, and provide authentication and review features through the web interface.
